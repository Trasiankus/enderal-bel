# enderal-bel

Выдавецтва Трасянкус прадстаўляе: **Enderal: Forgotten Stories** цалкам на беларускай мове.

Гэты рэпазіторый зроблены для дапрацоўкі перакладу. Калі знайшлі памылку — зчэкаўціце
рэпазіторый, выпраўце і дашліце PR. Калі ласка, не рабіце PR-ы занадта вялікімі.
Для зручнай праўкі раю Notepad++ або VS Code, толькі загадзя выключыце аўтадапаўненне —
файлы вялікія і рэдактар будзе тармазіць.

Пераклад зроблены **з рускай як асноўнай крыніцы**, з англійскай як даведкай:
руская лакалізацыя афіцыйная і задае тэрміналогію, а англійская кіруе структурай і
разметкай. Правапіс — **наркамаўка**.

## Змест рэпазіторыя

| Файл | Што гэта |
|---|---|
| `localization.json` | Кароткія і сярэднія радкі: `{ ключ: {"en": …, "ru": …, "bel": …} }` |
| `books.json` | Кнігі, лісты і доўгія тэксты, **разбітыя на абзацы** — так іх можна чытаць і глядзець дыфы |
| `interface.json` | Тэкст меню (Flash-інтэрфейс, `Interface/translate_*.txt`) |
| `map.json` | Службовае: які ключ у якім файле гульні ляжыць. Не чапайце |
| `scripts/make_mod.py` | Збірае мод у папку `mod/` |
| `scripts/check.py` | Правярае пераклад перад PR |
| `scripts/strings.py` | Чытанне/запіс фармату `.strings` / `.dlstrings` / `.ilstrings` |

**Змяняйце толькі поле `bel`.** Палі `en` і `ru` — арыгіналы з гульні, яны абнаўляюцца
напрамкі і вашыя праўкі ў іх згубяцца.

## Кнігі

Кніга захоўваецца так:

```json
"f098d149046fd545": {
  "bel": ["Першы абзац…", "Другі абзац…"],
  "sep": ["\r\n\r\n"],
  "en":  ["First paragraph…", "Second paragraph…"],
  "ru":  ["Первый абзац…", "Второй абзац…"]
}
```

- `bel` — абзацы перакладу, па адным на элемент. Праўце іх.
- `sep` — што стаіць **паміж** абзацамі (пустыя радкі — гэта вёрстка старонкі ў гульні).
  Звычайна чапаць не трэба. Калі дадаяце абзац, дадайце і раздзяляльнік.
- `en` / `ru` — арыгіналы для даведкі.

Колькасць абзацаў у `bel` можа не супадаць з `en` — руская лакалізацыя таксама
месцамі аб'ядноўвае абзацы. Гэта нармальна.

## Што нельга ламаць

- **Няма літар и, щ, ъ.** Беларуская мова іх не мае: пішыце **і**, **шч**, **'**.
- **Разметка застаецца як ёсць**: `<font …>`, `</p>`, `<mag>`, `<dur>`, `%s`, `[pagebreak]`,
  назвы кнопак `[Activate]`. Тое, што гульня падстаўляе сама, перакладаць нельга.
  Але падказкі дыялогаў (`<Attack>`) і подпісы (`[DANGER]`) — гэта звычайны тэкст,
  яго перакладаць трэба (глядзіце, як зрабіла руская).
- **Наркамаўка, не тарашкевіца**: ёсць (не ёсьць), жыццё (не жыцьцё), смерць (не сьмерць).

`scripts/check.py` правярае ўсё гэта аўтаматычна.

## Як сабраць мод

Патрэбны Python 3 і ўсталяваная гульня (адтуль бяруцца ідэнтыфікатары радкоў).

```
python scripts/check.py                    # праверыць пераклад
python scripts/make_mod.py --check         # праверыць, ці ўсё на месцы
python scripts/make_mod.py                 # сабраць у mod/
```

Калі гульня не ў стандартнай папцы:

```
python scripts/make_mod.py --game "D:\Games\Enderal Special Edition"
```

Потым скапіруйце змесціва `mod/` у `Data/` гульні.

## Усталяванне

Гульня чытае толькі файлы са сваёй мовай — `Strings\<назва>_<sLanguage>.*`. Таму мод
змяшчае **абодва** варыянты, `_english` і `_russian`, з аднолькавым беларускім тэкстам:
на англійскай зборцы падхопіцца першы, на рускай — другі. Мяняць `sLanguage` не трэба.

Шрыфты: рускія шрыфты кніг не маюць літары **ў**, таму мод падмяняе тры слоты
(`$SkyrimBooks`, `$HandwrittenFont`, `$HandwrittenBold`) праз `Interface/fontconfig.txt`.
Шрыфты меню застаюцца арыгінальныя.

## Вядомыя абмежаванні

- Агучка застаецца англійскай.
- Некаторыя надпісы ўшытыя ў сам Flash (`.swf`) і пакуль не перакладзеныя.
- У вялікіх літарах **Ў** адлюстроўваецца не ва ўсіх меню — там, дзе шрыфт яе не мае,
  фармулёўка падабраная без яе.
